# Grafana Assistant for Codex

Codex skill for read-only investigations through the Grafana Assistant CLI.

## Prerequisites

- Install the `grafana-assistant` CLI from [Grafana Assistant CLI](https://github.com/grafana/assistant-cli).
- Authenticate the CLI to a Grafana instance where your user has access to Grafana Assistant.
- Use a Grafana account with the Assistant CLI User role, or the equivalent custom permission.

This plugin does not install the CLI, configure credentials, start a tunnel, or enable local terminal access.
